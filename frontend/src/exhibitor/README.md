# Exhibitor demo

Open `/?view=exhibitor`. Start with the exhibitor profile, then define a product launch, topic, audience goal, and offer. One booth contact and a preset Wednesday 1–2 PM activation replace team availability and coverage confirmation.

The audience separates peer-reported topic expertise from relevant connections. It is labeled Sample graph: these are seeded observations, not live graph results. Review the selected recipients and invitation before sending. Sending creates local invitations, never automatic attendance or external messages.

Open a recipient preview to accept or decline. Acceptance, booth check-in, and completed visits update the exhibitor response counts across tabs on the same origin. Finishing a visit requires feedback in the same modal. Exhibitors do not receive private feedback answers.

Setup uses `rally.pizza-exhibitor.v2` with version 4 payloads. Legacy setup is migrated into an incomplete profile. Campaigns and invitation lifecycle use `rally-pizza-promotions-v1`. The promotion store rejects configured live mode until backend mappings are agreed. No endpoints were added or changed.
